feedback.

Manual interview practice is highly time-consuming for both students and evaluators.

Students require a flexible system that allows interview practice anytime and anywhere.

Slide 6: AI Models and APIs Used
Core Artificial Intelligence Engine
Groq API Integration
• Used for generating questions, evaluating answers, and giving feedback.
• Selected because it provides incredibly fast AI responses.
Llama Large Language Models (LLMs)
• Llama 3.1 8B Instant: Used for rapid, low-latency response generation.
• Llama 3.3 70B Versatile: Used for deep reasoning and complex answer evaluation.

Slide 11: Challenges & Solutions
Problems Faced During Development
Audio Freeze Problem
Problem: Pressing the voice button many times caused the audio to stop working.
Solution: Added a reset function to clear old audio before playing a new voice message.
Quote and Syntax Errors
Problem: Questions containing single quotes or special symbols caused errors in JavaScript.
Solution: Used safe text formatting in the backend to handle special characters properly.
API or Network Failure
Problem: Slow internet or AI server issues sometimes interrupted the interview process.
Solution: Added error handling and backup questions to keep the system running smoothly.
